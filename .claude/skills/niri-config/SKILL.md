# niri / DMS config (dots)

## KDL syntax

Prefix a node with `/-` to comment it out:

```kdl
/-binds {
    Mod+Q { close-window; }
}
```

There is no line-comment-out for a whole block otherwise — `/-` applies to the next node, children included.

## Split config

`config.kdl` `include`s files under `dms/`. Put a change in the split file that owns it rather than inlining it into `config.kdl`.

## DMS-managed trees

DankMaterialShell writes parts of its own config, including plugin checkouts. Anything under a DMS-managed directory (plugin repos, generated settings) should be changed through DMS, not hand-edited — DMS will overwrite you.

`config.kdl.backup*` files are auto-generated by DMS. They're gitignored; leave them alone and don't treat one as the live config.
