# WezTerm

My [WezTerm](https://wezterm.org/) config. It's mostly about **quick select**
(`Alt+Space`): hinting URLs, paths and code on screen so one keypress copies them,
including from Claude Code and Neovim's rendered markdown, whose output breaks wezterm's built-in patterns.
Panes and splits are left to [herdr](../herdr/), so wezterm has no split binds.

![WezTerm running Neovim, Everforest via dank-theme](../nvim/screenshots/editing.png)

| File | What it holds |
|---|---|
| [`wezterm.lua`](.config/wezterm/wezterm.lua) | Font, padding, tab bar, quick select patterns |
| [`keys.lua`](.config/wezterm/keys.lua) | Keybindings and the quick select logic |
| [`claude-code-blocks.py`](.config/wezterm/claude-code-blocks.py) | Reads code blocks out of a Claude Code transcript for quick select |
| [`colors/dank-theme.toml`](.config/wezterm/colors/dank-theme.toml) | Colour scheme, regenerated by DankMaterialShell from the wallpaper |

## Worth stealing

- <a id="quick-select-prose"></a>**Quick select that doesn't grab surrounding
  punctuation.** wezterm's built-in URL pattern is the scheme plus `\S+`, so a URL
  at the end of a sentence or inside parentheses copies the `.` or `)` too. These
  patterns stop at delimiters, keep balanced parentheses as in
  `Foo_(bar)`, and don't let a path end on a dot.
  [`wezterm.lua`](.config/wezterm/wezterm.lua) ·
  [3f61730](https://github.com/HefKer/dots/commit/3f61730)
- <a id="hard-wrapped"></a>**Copy URLs and paths that a TUI hard-wrapped.**
  Fullscreen TUIs like Claude Code break a long URL into separate rows, and quick
  select only sees the first one. The copy action joins the rows that run to the
  right edge back together.
  [`keys.lua`](.config/wezterm/keys.lua) (`join_hard_wrapped`) ·
  [7dc5738](https://github.com/HefKer/dots/commit/7dc5738)
- <a id="claude-inline-code"></a>**Hint inline code in Claude Code.** Claude Code
  drops the backticks around inline code and colours it bright blue instead. The
  Lua API can't see colours, so `keys.lua` asks `wezterm cli` for the escape
  sequences and hints those spans.
  [`keys.lua`](.config/wezterm/keys.lua) ·
  [eb33db7](https://github.com/HefKer/dots/commit/eb33db7)
- <a id="nvim-inline-code"></a>**Hint inline code in Neovim's rendered
  markdown.** render-markdown.nvim hides the backticks and gives inline code a
  background of its own. `keys.lua` hints spans whose background differs from
  the text on both sides, then learns their colour to also catch code on the
  cursor line and in headings, where the background doesn't stand out.
  [`keys.lua`](.config/wezterm/keys.lua) (`inline_code`)
- <a id="claude-code-blocks"></a>**Copy whole code blocks from Claude Code.** On
  screen, a code block has no fences and is wrapped at the pane edge. Inside herdr,
  the session transcript is reachable, so the row holding each block's first line
  gets a hint, and picking it copies the block exactly as written.
  [`claude-code-blocks.py`](.config/wezterm/claude-code-blocks.py) ·
  [256ffb2](https://github.com/HefKer/dots/commit/256ffb2)
- <a id="alt-scroll"></a>**`Alt+j/k/u/d` scrolls the scrollback, except in
  fullscreen apps.** When the pane is on the alternate screen (nvim, less, a TUI),
  the keys go through to the app instead.
  [`keys.lua`](.config/wezterm/keys.lua) (`alt_scroll`) ·
  [10428f0](https://github.com/HefKer/dots/commit/10428f0)
- <a id="tab-bar-theme"></a>**Tab bar coloured from the generated scheme.**
  DankMaterialShell regenerates `dank-theme.toml` without a tab bar section, so
  `wezterm.lua` loads the scheme and builds the tab colours from it rather than
  hardcoding them. [`wezterm.lua`](.config/wezterm/wezterm.lua) ·
  [de43f7e](https://github.com/HefKer/dots/commit/de43f7e)

## Using it yourself

- The two Claude Code entries only work in Claude Code. The code-block one also
  needs [herdr](https://herdr.dev), which tells it which session is in the pane.
  Everything else is plain wezterm.
- `dank-theme` is generated by
  [DankMaterialShell](https://github.com/AvengeMedia/DankMaterialShell). Without
  it, set `config.color_scheme` to one of wezterm's built-in schemes and the tab
  bar follows.
- Font: [Victor Mono](https://rubjo.github.io/victor-mono/).
