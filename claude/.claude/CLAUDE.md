To find past Claude Code work, including subagents, run `~/dots/scripts/session-find <text>` (`--help` for filters) before scanning transcripts by hand.

Be extremely concise.  Sacrifice grammar for the sake of concision.

Windows you open to test or screenshot something go to the screen the user isn't on, unfocused, so their typing stays in their own window: run them through `~/dots/scripts/claude-shot`, or give the window the app-id `claude-shot-<that output>`, which niri's rules open floating there.
